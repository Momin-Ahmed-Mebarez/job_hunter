Job Validator Configuration

Configure the language models used to validate job listings.

LLM Validation

Enable AI-based validation for collected jobs.

CV Validation

Model responsible for extracring rules from your CV. The rules are used to determine whether a job matches you or not. If not provided create a cv_rules.txt in prompts folder. Only open-ai compatibile models are supported. (feel free to change helpers/llm.py to support others).

Optional

Title Validation

Optionally reject irrelevant jobs using only their title before running more expensive models. Only open-ai compatibile models are supported. (feel free to change helpers/llm.py to support others).

Optional

Job Description Validation

Model used to inspect and validate the full job description. Only open-ai compatibile models are supported. (feel free to change helpers/llm.py to support others).
